## Decode
```
byte0     = 0x12 magic
byte1..2  = checksum16 LE
byte3     = 0x3c write
byte4..5  = 00 11   block selector = LED effect
byte6     = LED index (0x03 here)
byte7     = 01
byte11-12 = 40 1f   config address (0x1f40)
byte13..22= 6c 07 e8 03 e8 03 f4 01 00 00   template (copy verbatim); e8 03=1000, f4 01=500 (speed/duration params)
byte23    = 0x42    light/color mode flags (Static Color)
byte24    = 00
byte25    = 0x64    (=100) light duration
byte26    = 0x64    (=100) dark duration
byte27    = R
byte28    = G
byte29    = B
byte30    = 0x02    LED class/type
```
